# ADR

## Accepted

### ADR-0002 20261109-073000
- gen は日の節の最新の時間見出しより後だけを追記し、HTML コメントの印と hash を書かない
  - ADR-0001 を撤回
  - 理由: 確定済みの行に触らなければ、機械が書いた行と手書きの行を見分ける必要がない
  - 受け入れた代償: 再実行の区切りごとに見出しが分かれる (1 時間に 1 つまで)
  - 受け入れた代償: 確定済みの時間帯に後から届いた情報は反映しない
- 例外: 完了した task の checkbox だけは確定済みの範囲でも更新する
  - 理由: task は作業の後で完了するので、更新しないと `[ ]` のまま残る
- 却下: 確定済みの範囲に足りない link を足し続ける
  - 確定済みの節に行が増える

## Deprecated

### ADR-0001 20261107-133000 [Deprecated -> ADR-0002]
- gen 区画は開始と終了の HTML コメント行で囲み、開始行に中身の hash を書く
  - 形: `<!-- his gen <hash> -->` ... `<!-- his gen end -->`
  - 中身が hash と一致する区画だけを、再実行で置き換える
- 却下: hash の状態をログの外のファイルに持つ
  - ログを手で移す・消すと、外の状態と中身がずれる
- 却下: 開始行だけに hash と行数を書く
  - 区画の終わりが目で見て分からない
